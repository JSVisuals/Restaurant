# JS Restaurant — Premium Restaurant Website

## Included
- Responsive premium restaurant landing page
- Sticky navigation + mobile menu
- Hero, About, Menu, Experience, Gallery
- Appointment/Table booking form
- WhatsApp booking flow
- Call Now + WhatsApp buttons
- Working hours and map section
- Final CTA + footer
- SEO meta description and semantic HTML
- Accessible labels, focus states and responsive layouts
- Lightweight scroll reveal animations

## Replace before publishing
1. Restaurant address in `index.html`
2. Phone/WhatsApp number in `index.html` and `script.js`
3. Google Maps link in the map section
4. Menu names/prices
5. Gallery/food images if the customer has original photos
6. Restaurant logo/name if needed

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## Important
The booking form currently opens WhatsApp with the submitted details. Replace `916301865012` with the customer's WhatsApp number before delivery.
